## Projeto em destaque

### Dh73 Dependency Lab

Ferramenta educativa para analisar dependências de projetos Node.js localmente e sem conexão com serviços externos. Lê arquivos `package-lock.json`, compara versões instaladas com um snapshot local ou uma base OSV importada e classifica vulnerabilidades por intervalos SemVer.

- Interface web e ferramenta de linha de comando
- Suporte a lockfiles npm v2 e v3
- Importação local de dados OSV
- Processamento local dos arquivos analisados

[Ver repositório](https://github.com/dhonorio73/dh73-dependency-lab) · [Acessar demonstração](https://dhonorio73.github.io/dh73-dependency-lab/)
